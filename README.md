# WordDaily — 10 английских слов каждый день

Одностраничный трекер английских слов с курсом на 1000 слов, интервальным повторением и встроенным YouTube-плейлистом. Работает полностью в браузере, без сервера и регистрации.

## Возможности

- **Курс на 1000 слов / 100 дней** — по 10 слов в день, слова не повторяются.
- **Карточки и повторение** — интервальное повторение (1 → 3 → 7 → 14 → 30 → 60 дней) и слова из прошлых уроков.
- **Прогресс курса** — серия дней, тепловая карта, статистика выученного.
- **Видео** — плейлист «Английский язык до автоматизма» с поиском, фильтрами и переходом к любому из 1033 уроков.
- **Слова из плейлиста** — личный блокнот: добавляйте слова и переводы, редактируйте, ищите и удаляйте.
- **Тёмная тема** — автоматически подстраивается под системную.
- **Русский интерфейс**.

## Запуск

Самый простой способ — открыть `index.html` в браузере.

Для встроенного YouTube-плеера (без ошибки 153) нужен HTTP-адрес. Любой статический сервер подойдёт, например:

```bash
npx serve .
# или
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите файлы (`index.html`, `README.md`, `.gitignore`, `.nojekyll`).
2. Откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

На GitHub Pages сайт открывается по HTTPS, поэтому YouTube-плеер работает встроенно.

## Данные и приватность

- Прогресс, выученные слова и блокнот хранятся в `localStorage` браузера под ключом `worddaily.v1`.
- Никакие данные не отправляются на сервер и не попадают в репозиторий.
- Прогресс привязан к адресу сайта: при переходе с `file://` или `localhost` на GitHub Pages он не переносится и начнётся заново.
- На разных устройствах прогресс не синхронизируется — у каждого браузера своя история.
